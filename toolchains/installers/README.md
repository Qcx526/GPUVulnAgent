# Installers

Large installer packages are not committed to git. When an installer is needed, it is
downloaded here and recorded in `../manifests/toolchain_manifest.json` with its SHA256 and
provenance URL.

Currently recorded: the nvJPEG 13.2.2 package extracted from the CUDA 13.4 installer was
copied (not linked) into `../cuda/nvjpeg/13.2.2/`.
