# data/

Working data that is not research evidence:

- `cases/` — case definitions used by the benchmark runner (one directory per case).
- `benchmarks/` — benchmark run outputs: `runs/<case>/<mode>/<tag>/<run_id>/` and
  `summary/index.json`. These are generated, not hand-edited.
- `knowledge/` — reference material a case may cite.

Historical experiments are NOT here; they live in `research_archive/`.
